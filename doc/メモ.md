## 構成（2026-09-13 トップページ作成）

- `index.html` / `css/style.css` / `js/main.js` / `assets/img/` のビルド不要な静的構成。
- 元デザインは `doc/design-index.png`（`Downloads/ses_hp_assets/index.png` のコピー）。
- 素材は `assets/img/` に英語名でコピー済み。ChatGPT生成のPNGは余白が大きいので、PILで透過部分をトリミングして縮小した（アイコン240px、ロゴマーク320px、筆記体1200px）。
- 高解像度オフィス写真はPNG 1.5MB → JPG 93KB に変換して使用。
- フォント: Google Fonts の Noto Sans JP（本文）+ Montserrat（英字ラベル・ロゴ文字）。
- ブレークポイント: 1080px（強み4列→2列）/ 960px（ハンバーガーメニュー）/ 900px（ABOUT・カード縦積み）/ 640px（スマホ）。

## ブラウザ確認の手順

- `python3 -m http.server <port> --bind 127.0.0.1 --directory <project>` でローカル配信。ポート8765は別プロジェクトが使用中のことがあるので、起動前に `lsof -nP -iTCP:<port> -sTCP:LISTEN` で空きを確認する。
- Claude in Chrome の `resize_window` は環境によって効かない。レスポンシブ確認は、scratchpad にプロジェクトへのシンボリックリンクを置き、任意幅の iframe を並べたハーネスHTMLを別ポートで配信して行うと確実（同一オリジンなので親からJSでスクロール操作もできる）。
- `scroll-behavior: smooth` を当てていると `window.scrollTo(0, y)` がアニメーションになり、直後の取得値がずれる。検証時は `scrollTo({top, behavior: 'instant'})` を使う。
- スクロール表示アニメーション（IntersectionObserver）は iframe 内だと発火が遅れる。スクリーンショット前に2秒程度待つ。

## ハマりどころ

- ヘッダーに `backdrop-filter` を付けると、その子孫の `position: fixed` 要素はヘッダーを基準に配置されてしまう（containing block になる）。ドロワーメニューが切れる原因だった。ぼかしは `.header::before` 擬似要素側に持たせて回避した。

## レビューで直した点（2026-09-13 Opus 4観点レビュー）

- 演出用の `html.js` クラスを head で先付けする場合、main.js が読めないと `.js-reveal` 要素が透明のまま残る。head 側に「一定時間内に `js-ready` が付かなければ `js` を外す」保険を入れておく。
- `aspect-ratio` と `min-height` を同時に指定したカードは、min-height 経由で幅が伝播してグリッド列を押し広げる（1000px前後で横スクロールが出た）。カードは `min-height` のみにする。
- スキップリンクは `position: fixed` にする。`absolute` だとスクロール済みの状態でフォーカスしたとき画面外に出る。
- iOS を含めたドロワー表示中のスクロール固定は、`html { overflow: hidden }` ではなく body を `position: fixed` にして `top: -scrollY` を JS で退避・復元する。ヘッダー（sticky）も同時に fixed に切り替えると位置がずれない。
- ドロワーを開いたら `main` / `footer` に `inert` を付けて背面をフォーカス・支援技術から外し、Tab はドロワー内＋トグルボタンでループさせる。
- デザイン画像との照合は、PIL で該当領域を切り出して拡大表示すると細部（タグの角丸、斜線の位置、ラベル色）を正確に判断できる。
- ChatGPT生成の透過PNGは、実表示サイズの約3倍（DPR3想定）まで縮小すれば十分。favicon は正方形キャンバスに中央配置して別途書き出す。
- Google Fonts で読み込むウェイトは、CSS で使う値を全て含めること。Montserrat を 600/700 だけ読み込むと、`font-weight: 400` 指定の要素も 600 で描画される（フォントマッチングの仕様）。
- 画像は WebP に統一（写真は quality 80〜82、透過PNG由来はロスレス）。元の JPG/PNG は `Downloads/ses_hp_assets` にあり、PIL で再生成できる。合計 660KB → 259KB。
- Google Fonts の CSS は `rel="preload" as="style"` + `onload` で stylesheet に切り替える非同期読み込みにした。Lighthouse モバイルの「レンダリングブロック」が主因の減点だった。
- ロゴリンクに `aria-label` を付けると、表示テキスト（タグライン含む）と一致せず Lighthouse の label-content-name-mismatch に引っかかる。表示テキストをそのままアクセシブルネームにする。
- Lighthouse は `npx --yes lighthouse@latest <url> --preset=desktop --output=json --chrome-flags="--headless=new"` で CLI 実行できる。axe-core は cdnjs からページに `<script>` 注入して `axe.run()` で実行できる。
- グリッドの `align-items: center` は各アイテムの stretch を解除するので、`border-left` で区切り線を描く場合は行の高さいっぱいに伸びなくなる。中央揃えはアイテム内側（flex）で行い、グリッド側は stretch のままにする。
- 高さが `min-height` だけの親に対する `height: 100%` は解決されない前提で書く。カード本文を下に寄せたい場合は親を flex コンテナにして本文に `flex: 1 0 auto` を与える。
