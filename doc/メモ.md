## 構成（2026-09-13 トップページ作成）

- `index.html` / `css/style.css` / `js/main.js` / `assets/img/` のビルド不要な静的構成。
- 元デザインは `doc/design-index.png`（`Downloads/ses_hp_assets/index.png` のコピー）。
- 素材は `assets/img/` に英語名でコピー済み。ChatGPT生成のPNGは余白が大きいので、PILで透過部分をトリミングして縮小した（アイコン240px、ロゴマーク320px、筆記体1200px）。
- 高解像度オフィス写真はPNG 1.5MB → JPG 93KB に変換して使用。
- フォント: Google Fonts の Noto Sans JP（本文）+ Montserrat（英字ラベル・ロゴ文字）。
- ブレークポイント: 1080px（強み4列→2列）/ 960px（ハンバーガーメニュー）/ 900px（ABOUT・カード縦積み）/ 640px（スマホ）。

## ブラウザ確認の手順

- `python3 -m http.server <port> --bind 127.0.0.1 --directory <project>` でローカル配信。ポート8765は別プロジェクトが使用中のことがあるので、起動前に `lsof -nP -iTCP:<port> -sTCP:LISTEN` で空きを確認する。
- Claude in Chrome の `resize_window` は環境によって効かない。レスポンシブ確認は、scratchpad にプロジェクトへのシンボリックリンクを置き、任意幅の iframe を並べたハーネスHTMLを別ポートで配信して行うと確実（同一オリジンなので親からJSでスクロール操作もできる）。
- `scroll-behavior: smooth` を当てていると `window.scrollTo(0, y)` がアニメーションになり、直後の取得値がずれる。検証時は `scrollTo({top, behavior: 'instant'})` を使う。
- スクロール表示アニメーション（IntersectionObserver）は iframe 内だと発火が遅れる。スクリーンショット前に2秒程度待つ。

## ハマりどころ

- ヘッダーに `backdrop-filter` を付けると、その子孫の `position: fixed` 要素はヘッダーを基準に配置されてしまう（containing block になる）。ドロワーメニューが切れる原因だった。ぼかしは `.header::before` 擬似要素側に持たせて回避した。
